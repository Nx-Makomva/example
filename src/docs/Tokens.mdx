# Tokens

A token is a named design decision. Code never says "this red". It says "the concern colour". Change the token, and every screen that uses it changes with it.

Tokens are named by **meaning**, never by look. Use them in Tailwind classes, for example `bg-concern-subtle text-concern` or `rounded-card shadow-card`. Tailwind's built-in palette (`bg-red-500`) is switched off, so only these tokens exist.

The source of truth is `src/app/globals.css`. To propose a new token, see *Proposing something new* in `DESIGN-SYSTEM.md`.

## Status

Each status colour has a `-subtle` pair. Use the full colour for text on its own `-subtle` fill, as `Badge` does. Status colours always come with text, never colour alone.

## Spacing and type size

These use Tailwind's standard scale. Spacing goes in steps of 4 px (`gap-4` is 16 px, `p-5` is 20 px). Type sizes are `text-sm`, `text-base`, `text-lg`, `text-3xl` and so on. Exact values in square brackets (`p-[13px]`) are blocked by lint.
