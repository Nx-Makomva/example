## Claude Code extras

- The contribution skills in `AGENTS.md` (*How to make a change*) are slash commands here: `/start-change`, `/preview-locally`, `/design-review`, `/explain-diff`, `/finish-work`, `/create-pr`, `/address-review`. When the user asks for a change while on `main`, start with `/start-change`.
- The Storybook MCP server (`.mcp.json`) works only while `pnpm storybook` is running. If its tools fail to connect, start Storybook, or read `src/components/` and `DESIGN-SYSTEM.md` instead.
